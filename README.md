Repositório com atividades e exercícios práticos de HTML e CSS, organizados por módulo de estudo.

## 📂 Estrutura

| Pasta | Conteúdo |
|---|---|
| `html-css-modulo1/` a `html-css-modulo5/` | Exercícios progressivos de HTML e CSS, por módulo |
| `atividades-curso-dimitri/` | Atividades do curso complementar |

## ▶️ Como usar

```bash
git clone https://github.com/Gabrielrlp/Estudos-html-css.git
```

Depois é só abrir o arquivo `.html` desejado diretamente no navegador.
